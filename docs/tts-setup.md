# Настройка озвучки (TTS) в Soul of Waifu (Linux)

Простыми словами: как заставить персонажа **говорить**, какие движки бывают,
что работает без интернета, а что нет, и что будет скачиваться при первом
использовании.

---

## Как выбрать движок озвучки

1. Открой окно персонажей и нажми на карточке персонажа кнопку **голоса**
   (иконка динамика) — откроется окно **Text-To-Speech Selector**.
2. В левой колонке **SPEECH ENGINES** выбери движок, справа настрой голос.
3. Нажми **Select Voice / Save** — выбор сохраняется **для этого персонажа**
   (в `~/.config/soul-of-waifu/characters.json` это поле
   `current_text_to_speech`, а сам голос — `voice_type`).

Движок «None / Nothing» = персонаж молчит (только текст).

> Дополнительно в основных настройках есть режим **TTS Voicing Mode** — что
> именно озвучивать: всё подряд, только реплики в кавычках, всё кроме
> звёздочек-действий, текст вне кавычек или по своей регулярке.

---

## Движки: что есть и что выбрать

| Движок | Где работает | Русский язык | Интернет | Скачивание при первом запуске |
|---|---|---|---|---|
| **Edge TTS** | онлайн (Microsoft) | да (голоса ru-RU) | **нужен** | ничего (~100 КБ список голосов) |
| **Silero (RU)** | локально | **да, специально для русского** | при первом запуске | ~50 МБ (torch.hub, кэш `~/.cache/torch/hub`) |
| **Kokoro** | локально | **нет** (только английский) | при первом запуске | ~400 МБ (HF-кэш `app/models/hf_cache`) |
| **XTTSv2** | локально | да (многоязычный) | при первом запуске | ~2 ГБ (HF-кэш `app/models/hf_cache`) |
| **Qwen-3 TTS** | локально | да | при первом запуске | 1–4 ГБ (HF-кэш `app/models/hf_cache`) |
| **ElevenLabs** | облако | да | нужен всегда | ничего, нужен платный API-ключ |
| **ComfyUI** | локальный сервер ComfyUI | зависит от воркфлоу | нет (если сервер свой) | зависит от воркфлоу |

**Короткие рецепты:**

- Хочу **по-русски** и просто → **Edge TTS** (если есть интернет) или
  **Silero (RU)** (полностью локально).
- Хочу локально и качественно по-русски → **XTTSv2** или **Qwen-3 TTS**
  (тяжёлые, нужен запас места/памяти; на GPU заметно шустрее).
- Хочу английский локально и легко → **Kokoro**.

## Про каждый движок подробнее

### Edge TTS (самый простой, но онлайн)

Бесплатный сервис озвучки от Microsoft. API-ключ не нужен.

- В окне движка выбери **язык** (`English` / `Russian`) и голос из списка —
  для русского это голоса с префиксом `ru-RU-` (например, `ru-RU-SvetlanaNeural`,
  `ru-RU-DmitryNeural`).
- **Требует интернет при каждой озвучке** — текст уходит на сервера Microsoft.
- Для конвертации mp3→wav нужен системный **ffmpeg**
  (`sudo pacman -S ffmpeg` на Arch — в большинстве случаев уже стоит).
- Опционально можно включить **RVC** — подмену голоса своей моделью из
  `assets/rvc_models/` (поля RVC в том же окне).

### Silero (RU) — локальный русский движок

Единственный движок, заточенный именно под **русский** и при этом маленький.

- Голоса: `aidar`, `baya`, `kseniya`, `xenia`, `eugene`.
- Модель скачивается один раз через torch.hub (~50 МБ) в `~/.cache/torch/hub`
  (это НЕ папка приложения), дальше работает полностью офлайн.
- Работает и на CPU — подойдёт для слабых машин.

### Kokoro — лёгкий локальный английский

Очень приятное качество голоса при размере модели всего 82M параметров.

- **Важно: Kokoro в приложении говорит только по-английски**
  (в коде захардкожен пайплайн `lang_code='a'` — американский английский).
- Голоса в GUI: `af_heart`, `af_bella`, `af_nicole`, `af_kore`, `am_michael`,
  `am_puck`, `bf_emma`, `bm_george` и др. (префикс `af_`/`am_` — американские,
  `bf_`/`bm_` — британские).
- Пакет `kokoro` уже установлен в `.venv` (проверено: `import kokoro` — OK).
  **Модель не скачана заранее**: при первой озвучке с интернета скачается
  `hexgrad/Kokoro-82M` + файлы голосов (~400 МБ) в `app/models/hf_cache`
  (приложение само прописывает `HF_HOME` на эту папку).
- Желательно поставить системный **espeak-ng** (`sudo pacman -S espeak-ng`):
  без него английский работает, но редкие/незнакомые слова будут пропускаться
  (Kokoro использует espeak-ng как запасной произноситель). На этой машине
  espeak-ng сейчас не установлен.
- Если ComfyUI-TTS недоступен, приложение автоматически падает именно на
  Kokoro — поэтому он и стоит вторым в `tts_engine_order`.

### XTTSv2 — локальный многоязычный (в т.ч. русский)

Классический Coqui XTTSv2 через библиотеку `TTS` (уже в `.venv`).

- При первой озвучке скачает модель `tts_models/multilingual/multi-dataset/xtts_v2`
  (~2 ГБ) в `app/models/hf_cache`. Библиотека Coqui при первом запуске может
  попросить согласиться с лицензией (CPML) — если увидишь такой вопрос,
  подтверди; для тихого запуска можно задать переменную окружения
  `COQUI_TOS_AGREED=1` перед стартом.
- Понимает несколько языков, включая русский.
- Тяжёлый: на CPU медленный, с NVIDIA GPU (CUDA) — комфортно.
- Есть RVC-подмена голоса (как у Edge).

### Qwen-3 TTS — локальный, самый свежий

Модели `Qwen/Qwen3-TTS-12Hz-*` через библиотеку `qwen_tts` (уже в `.venv`).
Настраивается на персонажа:

- **размер модели**: `0.6B (Fast)` или `1.7B (High Quality)`;
- **режим**: `Preset Voices (CustomVoice)` — готовые голоса (Serena, Vivian,
  Aiden, Dylan, Eric, Ryan, Uncle_Fu, Ono_Anna, Sohee), `Voice Design (Prompt)`
  — голос описывается текстом, `Voice Cloning` — клонирование по 3-секундной
  аудиозаписи;
- **устройство**: `CUDA (GPU)` или `CPU`.

Модель скачивается с Hugging Face в `app/models/hf_cache` при первом
использовании (от ~1 ГБ для 0.6B до ~4 ГБ для 1.7B). В HF-кэше этой машины
уже есть частичная загрузка `Qwen3-TTS-12Hz-1.7B-Base`.

### ElevenLabs — облачный, платный

- Нужен API-ключ: вставляется в настройках API (сохраняется в
  `~/.config/soul-of-waifu/api.json` как `ELEVENLABS_API_TOKEN`), плюс ID
  голоса (`elevenlabs_voice_id`) в окне движка.
- Модель `eleven_multilingual_v2` — говорит и по-русски.
- Бесплатный лимит маленький, дальше — платно.

### ComfyUI — озвучка через свой ComfyUI

Если у тебя уже крутится ComfyUI (например, для картинок), TTS можно вынести
туда:

1. Запусти ComfyUI (адрес по умолчанию `http://127.0.0.1:8188`, меняется в
   `media.yaml` → `comfyui.base_url`).
2. В ComfyUI собери TTS-воркфлоу и экспортируй кнопкой **Save (API Format)**.
3. Положи полученный `.json` в drop-in папку:
   ```
   app/data/workflows/tts/*.json
   ```
4. (Опционально) рядом положи `<имя>.meta.yaml`, где укажи
   `text_node_id` (куда подставлять текст) и `output_node_id` — без него
   приложение само найдёт ноды по типам.
5. В окне выбора движка у персонажа нажми **ComfyUI → Save**.

Первый найденный воркфлоу становится активным пресетом. Если ComfyUI
недоступен — озвучка автоматически уйдёт на встроенный Kokoro.

## Порядок запасных движков: `tts_engine_order` (media.yaml)

В `~/.config/soul-of-waifu/media.yaml` есть ключ:

```yaml
tts_engine_order: [comfyui, kokoro]
```

Это **цепочка фолбэков**: движок, выбранный в GUI, всегда пробуется первым,
а остальные элементы списка — запасные, если основной упал или вернул пустоту.
Допустимые имена: `comfyui`, `kokoro`, `xttsv2`, `edge`, `silero`, `qwen3`,
`elevenlabs`.

Пример: хочешь «сначала ComfyUI, если он не поднялся — Silero, в крайнем
случае Kokoro»:

```yaml
tts_engine_order: [comfyui, silero, kokoro]
```

Пустой/отсутствующий список — старое поведение: только выбранный движок
(у ComfyUI остаётся запасной Kokoro). Логи фолбэков пишутся в лог приложения
(`log_tts_engine_fallback`).

## Куда пишутся файлы

| Что | Где |
|---|---|
| HF-модели (Kokoro, XTTSv2, Qwen3-TTS) | `app/models/hf_cache` (`HF_HOME` прописан приложением) |
| Модель Silero | `~/.cache/torch/hub` |
| Аудио-выход движков | `app/voices/edge_tts_audio/`, `app/voices/elevenlabs_audio/` и т.п. |
| Сегменты для «перепроигрывания» реплик | `app/data/.soul/<персонаж>/tts_audio/<сообщение>/` |
| RVC-модели (подмена голоса) | `assets/rvc_models/` |

## Частые проблемы

- **«Выбрал движок, а тишина»** — посмотри лог запуска: при ошибке движка
  приложение переключится на запасной из `tts_engine_order` и напишет причину.
- **Kokoro молчит/скачивает при каждой генерации** — первый запуск требует
  интернет; убедись, что модель появилась в `app/models/hf_cache`.
- **Edge TTS не работает без сети** — это нормально, он онлайн. Для офлайна
  бери Silero (русский) или Kokoro (английский).
- **Русский персонаж говорит на английском** — Kokoro не умеет русский, возьми
  Edge TTS с голосом `ru-RU-*` или Silero (RU).
- **Нет звука вообще** — проверь выбор устройства вывода в основных настройках
  (Output Device).
